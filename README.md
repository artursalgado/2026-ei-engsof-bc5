# Requesitos Projeto - Gestão de Talentos e Propostas

## Base de Dados
- Desenhar DER da Base de Dados (DB)
- Configurar ligação da DB ao projeto
- Instalar e configurar Entity Framework Core  
- Criar tabelas restantes

## Autenticação e Autorização
- Registo de utilizador
- Login
- Logout
- Hash automático de passwords
- Sistema de Roles (Admin / User)
- Restringir páginas com `[Authorize]`
- Redirecionamento após login
- Seed de roles iniciais

## Funcionalidades Principais

### Gestão de Skills
- Criar skill (Admin)
- Editar skill
- Apagar skill
- Listar skills

### Gestão de Perfis de Talento
- Criar perfil de talento
- Editar perfil
- Apagar perfil
- Listar talentos
- Ver detalhes de talento
- Associar múltiplas skills
- Remover skills do talento
- Pesquisar talento por nome
- Filtrar por skill
- Filtrar por localização

### Gestão de Propostas e Clientes
- Criar proposta
- Criar cliente
- Filtrar talentos elegíveis para uma proposta
